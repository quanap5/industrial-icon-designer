# Duotone SCADA set (synthetic)

Generated by `examples/build_style_examples.py` from the synthetic fixtures. The icons are not real product
artwork. Each master is an outline plus one translucent fill (`fill="currentColor"` at `fill-opacity="0.3"`): one colour at two opacities, no second palette token.

The review in `icon-work/scada-duotone/approvals.json` is an **agent** review recorded for an unattended run; it is
not human approval. The palette is provisional. Application validation is `not-tested` for every context.

| Path | Content |
|---|---|
| `references/` | The same inconsistent synthetic "legacy" PNG/SVG icons and `metadata.json` as the demo |
| `icon-work/scada-duotone/masters/` | The SVG masters (24 grid, `currentColor`) |
| `icon-work/scada-duotone/icon-style.md`, `style-spec.json` | Synchronized style documents, including `style_mode` |
| `icon-work/scada-duotone/preview/` | Open `index.html`; contexts are labeled simulations |
| `icon-work/scada-duotone/exports/` | Desktop PNGs and inline Web SVGs |
| `icon-work/scada-duotone/reports/` | Reference analysis, QA reports (with the consistency findings), application checklist |

Rebuild: `python examples/build_style_examples.py --only duotone`
