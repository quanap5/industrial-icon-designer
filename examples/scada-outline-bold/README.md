# Bold outline SCADA set (synthetic)

Generated by `examples/build_style_examples.py` from the synthetic fixtures. The icons are not real product
artwork. The outline masters of the demo at stroke 2 instead of 1.5, with a graphite provisional palette: the same geometry showing what a heavier stroke does to 16 px legibility.

The review in `icon-work/scada-outline-bold/approvals.json` is an **agent** review recorded for an unattended run; it is
not human approval. The palette is provisional. Application validation is `not-tested` for every context.

| Path | Content |
|---|---|
| `references/` | The same inconsistent synthetic "legacy" PNG/SVG icons and `metadata.json` as the demo |
| `icon-work/scada-outline-bold/masters/` | The SVG masters (24 grid, `currentColor`) |
| `icon-work/scada-outline-bold/icon-style.md`, `style-spec.json` | Synchronized style documents, including `style_mode` |
| `icon-work/scada-outline-bold/preview/` | Open `index.html`; contexts are labeled simulations |
| `icon-work/scada-outline-bold/exports/` | Desktop PNGs and inline Web SVGs |
| `icon-work/scada-outline-bold/reports/` | Reference analysis, QA reports (with the consistency findings), application checklist |

Rebuild: `python examples/build_style_examples.py --only outline-bold`
