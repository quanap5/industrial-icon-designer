# Outline set with filled selected states (synthetic)

Generated by `examples/build_style_examples.py` from the synthetic fixtures. The icons are not real product
artwork. The outline demo masters, plus a filled variant (`<id>-filled`) for four icons that have a selected state: `valve`, `pump`, `alarm-list` and `settings`. Each variant is its own master, judged as filled and checked against the box of its outline base.

The review in `icon-work/scada-selected-states/approvals.json` is an **agent** review recorded for an unattended run; it is
not human approval. The palette is provisional. Application validation is `not-tested` for every context.

| Path | Content |
|---|---|
| `references/` | The same inconsistent synthetic "legacy" PNG/SVG icons and `metadata.json` as the demo |
| `icon-work/scada-selected-states/masters/` | The SVG masters (24 grid, `currentColor`) |
| `icon-work/scada-selected-states/icon-style.md`, `style-spec.json` | Synchronized style documents, including `style_mode` |
| `icon-work/scada-selected-states/preview/` | Open `index.html`; contexts are labeled simulations |
| `icon-work/scada-selected-states/exports/` | Desktop PNGs and inline Web SVGs |
| `icon-work/scada-selected-states/reports/` | Reference analysis, QA reports (with the consistency findings), application checklist |

Rebuild: `python examples/build_style_examples.py --only selected-states`
