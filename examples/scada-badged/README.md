# Outline icons with a solid badge (synthetic)

Generated by `examples/build_style_examples.py` from the synthetic fixtures. The icons are not real product
artwork. Six icons drawn as a 0.72-scale outline main object plus one solid secondary object: a disc in the bottom-right corner with a plus (add), minus (remove) or check (done) cut out by `fill-rule="evenodd"`. Three icons have an explicit 16 px variant that drops detail, because the first pilot review refused them for clarity at 16 px.

The review in `icon-work/scada-badged/approvals.json` is an **agent** review recorded for an unattended run; it is
not human approval. The palette is provisional. Application validation is `not-tested` for every context.

| Path | Content |
|---|---|
| `references/` | The same inconsistent synthetic "legacy" PNG/SVG icons and `metadata.json` as the demo |
| `icon-work/scada-badged/masters/` | The SVG masters (24 grid, `currentColor`) |
| `icon-work/scada-badged/icon-style.md`, `style-spec.json` | Synchronized style documents, including `style_mode` |
| `icon-work/scada-badged/preview/` | Open `index.html`; contexts are labeled simulations |
| `icon-work/scada-badged/exports/` | Desktop PNGs and inline Web SVGs |
| `icon-work/scada-badged/reports/` | Reference analysis, QA reports (with the consistency findings), application checklist |

Rebuild: `python examples/build_style_examples.py --only badged`
