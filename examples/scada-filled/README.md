# Filled SCADA set (synthetic)

Generated by `examples/build_style_examples.py` from the synthetic fixtures. The icons are not real product
artwork. Every master is a solid shape with `fill="currentColor"` and `stroke="none"`; details are cut out with `fill-rule="evenodd"` or kept as separate gaps, never painted in a background colour.

The review in `icon-work/scada-filled/approvals.json` is an **agent** review recorded for an unattended run; it is
not human approval. The palette is provisional. Application validation is `not-tested` for every context.

| Path | Content |
|---|---|
| `references/` | The same inconsistent synthetic "legacy" PNG/SVG icons and `metadata.json` as the demo |
| `icon-work/scada-filled/masters/` | The SVG masters (24 grid, `currentColor`) |
| `icon-work/scada-filled/icon-style.md`, `style-spec.json` | Synchronized style documents, including `style_mode` |
| `icon-work/scada-filled/preview/` | Open `index.html`; contexts are labeled simulations |
| `icon-work/scada-filled/exports/` | Desktop PNGs and inline Web SVGs |
| `icon-work/scada-filled/reports/` | Reference analysis, QA reports (with the consistency findings), application checklist |

Rebuild: `python examples/build_style_examples.py --only filled`
